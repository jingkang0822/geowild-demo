# GeoWild public demo: exactly 100 species

## Authorization and implementation

Standard Development. The owner explicitly requested extending the public Pages job demo to 100 species, using one shared interaction contract and representative browser acceptance rather than clicking every species. Geographic answers must still be verified per species. Prior authorization to commit, push and deploy this independent demo remains applicable. The original production checkout is read-only.

1. Reuse the inspected original candidate bank as input; retain all original 17 IDs and select 83 additional supported species. Verify scientific identity, country provenance and licensed photo metadata. Freeze exactly 100 canonical records in `data/animals.json`; generate the runtime bank using the existing asset/build mechanism adapted to this release path. Keep original production files untouched.
2. Geography: retrieve primary MDD country-distribution data and original non-mammal authorities; distinguish definite from uncertain presence and exclude introduced populations. Record per-species source evidence and any documented corrections. A data-driven test applies real packaged country geometries and real engine scoring to every accepted country, plus known geographically separated independent location fixtures and negative guesses. Do not infer geographic correctness from a matching ID/code alone.
3. Shared interaction: keep the original engine/controller/globe path. State contract is photo loading -> guess or movable confirmation draft -> exactly-once reveal -> next question -> five-result total -> replay/home/share. Parameterized engine integration covers all 100 species, five multiplier positions, serialization and duplicate submission; real browser tests exercise this shared path once across representative rounds, failure recovery and mobile. All 100 photos must decode; 100 credits must be reachable without playing 100 rounds.
4. Reuse the existing release manifest and Pages workflow. Derive bank counts from canonical records where practical; update portfolio labels and share/metadata descriptions to 100. Preserve demo storage namespace and all existing species/answer inputs so stored rounds remain readable. Capture a legacy 17-species save fixture before scaling.
5. Run `yarn verify`, inspect staged changes, commit/push, wait for Pages verification/deployment, then repeat bounded shared browser flows on live HTTPS and check release hashes. Record geographic evidence and limits honestly; no physical-phone or habitat-precision claim.

## Principle choices

plan-before-code: b, this plan precedes edits and current owner instructions authorize execution. hard-right-over-easy: b, extend existing data/build/test owners rather than species-specific UI code. mechanism-over-name: b, assert every species traverses the actual engine and its geography, then compensate the browser boundary with the real shipped path. evidence-over-appearance: b, location sources plus geometric/scoring execution and live acceptance determine completion. no-unauthorized-data-loss: b, old IDs/saves remain readable and original working tree is untouched. core-over-coverage: b, exactly 100 species and existing interactions only. converge-knowledge: b, canonical data generates runtime output and evidence records retain upstream provenance.
